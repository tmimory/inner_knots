---
id: prisoners-dilemma/payoffs-symmetric
description: The bargain when both players face the same consequences. Each variable is one free-text outcome.
variables: [bothTestify, bothSilent, onlyTestifier, onlySilent]
---
The bargain is the same for both of you:

- If you both testify against each other, you each get {{bothTestify}}.
- If you both stay silent, you each get {{bothSilent}}.
- If one of you testifies and the other stays silent, the one who testified gets {{onlyTestifier}} and the one who stayed silent gets {{onlySilent}}.

Both of you have been told these terms, and both of you know the other has been told them.
